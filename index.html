Installing

A one-time setup. After that, VolleyCodec Pro updates itself whenever it's online.

On a Mac

  1. Open the downloaded .pkg and follow the installer.
  2. First time only — if macOS says it's from an unidentified developer: Control-click the file and choose Open, then Open again. (Or: System Settings → Privacy & Security → Open Anyway.)
  3. Launch VolleyCodec Pro from Applications and log in.
If it ever says the app is "damaged", it just means macOS hasn't cleared it yet — use Control-click → Open as above, and it will open normally.

On Windows

  1. Unzip the downloaded file (right-click → Extract All).
  2. Open the VolleyCodec Pro folder and run the installer inside.
  3. If Windows shows a blue SmartScreen notice: click More info → Run anyway.
  4. Launch VolleyCodec Pro and log in.
On the same Wi-Fi, iPads and phones can open the live scout from this computer — no install needed on those devices.

You'll need an account

VolleyCodec Pro signs in with a username and password. If you don't have one yet, ask the person who manages your team's VolleyCodec Pro accounts.
